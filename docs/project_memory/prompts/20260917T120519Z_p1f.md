====================
六、预先定义 collapse / shrinkage，不要事后命名
====================

在训练前给出 operational definitions。

至少区分：

1. mild shrinkage
branch contribution 明显低于 teacher，但仍非零且 recovery 可接受。

2. severe shrinkage
branch contribution 大幅下降，并伴随明显 recovery degradation。

3. collapse
branch contribution 接近数值零，且模型主要退化为 global-only solution。

阈值应基于 teacher branch scale / global control / numerical precision 制定，
并在 PROTOCOL 中冻结。

不要用单一 ||u|| 定义 collapse，
因为 u/h 存在 representation scaling/symmetry。
优先使用 function-level：
q(x)=(u^T x)h(x)
或 b(x)-beta
的 field norm。

====================
七、第一阶段判别逻辑
====================

跑完 P0 与 Pλ 后，按以下逻辑解释：

Case A:
P0 从 standard 或 teacher-local init 能恢复 teacher，
而 Pλ 稳定 shrink / collapse。

=> 强支持 regularization/objective-induced bias。
=> 可以进入第二阶段剂量与结构普适性检查。

Case B:
P0 和 Pλ 都失败 / 都 collapse。

=> 不能把问题主要归因于 regularization。
=> 优先检查 optimizer geometry / parameterization / identifiability。

Case C:
P0 和 Pλ 都能恢复 teacher。

=> 历史 collapse 更可能依赖 finite-sample / initialization / optimizer interaction。
=> positive penalty 存在理论 shrinkage bias，但不足以解释实际 collapse。

Case D:
Pλ 有稳定 shrinkage，但没有 collapse；
P0 recovery 更好。

=> 已证明 objective bias，
但“collapsed local basin 是历史主因”的证据仍不足。

不得把任何一种情况包装成预设故事。
