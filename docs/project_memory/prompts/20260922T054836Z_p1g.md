==================================================
collapse / shrinkage 的定义继续沿用 P1-F
==================================================

严格区分：

p：normalized density
g：scalar predictor
b：coefficient field
beta/u/h：anchored decomposition
theta：NN parameters

禁止用下面任何单一现象直接判 collapse：

- u norm 下降
- h norm 下降
- theta norm 下降
- b norm 下降
- penalty 下降

functional collapse 必须由 q / field contribution / density / predictor 的联合退化支持。

如果出现 u↓、h↑ 但 q 保持，
这是 parameter compensation，不是 collapse。

==================================================
预先规定的结果解释
==================================================

Case A
empirical_P0 正常，
empirical_Plambda 明显 shrink / collapse，
而 population 两条都正常：

→ 强烈支持 finite-sample × regularization interaction。
下一步才值得进一步拆 sample geometry / regularizer / optimizer mechanism。

Case B
empirical_P0 和 empirical_Plambda 都 collapse：

→ regularization 不是必要条件。
更支持 empirical objective geometry / optimization 本身。

Case C
empirical 两条都正常：

→ 在 lr=.003 / 48² 条件下不能复现历史 collapse。
说明历史现象还依赖其他因素，
最明显候选是旧 24² quadrature 或 lr=.01，
但本轮不要继续测试。

Case D
empirical_Plambda 比 P0 recovery 更差，
但没有 functional collapse：

→ 支持 finite-sample 下 regularization bias 增强，
但仍不能称 collapse mechanism。

Case E
参数 decomposition 剧烈变化，
functional outputs 基本一致：

→ representation / identifiability effect，
不算 functional failure。

Case F
regularized total loss 持续下降，
但 unregularized empirical PPP objective、
independent population KL 和 functional recovery 同时恶化：

→ 这是最重要的 objective-conflict 证据之一，
需要把转折 step 和 penalty/data-term tradeoff 明确画出来。
