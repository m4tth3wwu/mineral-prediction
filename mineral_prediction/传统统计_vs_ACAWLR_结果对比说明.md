# 传统统计学与 ACAWLR 结果对比

## 公平比较口径

ACAWLR 复现程序中的 Global logistic 与 ACAWLR 使用完全相同的 1 km 网格、44 个训练矿床、五折空间分组和 16 个外部验证矿床，因此这是主要比较依据。

| 指标 | 五折 Global logistic | 五折 ACAWLR | 外部验证 Global logistic | 外部验证 ACAWLR |
|---|---:|---:|---:|---:|
| AUC | 0.906 +/- 0.029 | 0.939 +/- 0.035 | 0.878 | 0.909 |
| PR-AUC | 0.530 +/- 0.109 | 0.571 +/- 0.103 | 0.427 | 0.471 |
| Accuracy | 0.960 | 0.960 | 0.958 | 0.964 |
| Precision | 0.606 | 0.583 | 0.595 | 0.788 |
| Recall | 0.473 | 0.576 | 0.375 | 0.322 |
| F1 | 0.529 | 0.575 | 0.460 | 0.457 |
| 假阳性 FP | - | - | 53 | 18 |
| 验证矿床命中数 | - | - | 9/16 | 7/16 |

## 简要结论

- ACAWLR 的 AUC、PR-AUC 和外部精确率更高，适合筛选少量高置信目标，并显著减少假阳性。
- Global logistic 的外部召回率和 16 个矿床命中数更高，更适合优先减少漏矿。
- 两者外部 F1 几乎相同，当前不能认为 ACAWLR 在所有指标上全面胜出。
- 传统点级分析采用 44 个矿床点和 5:1 背景点，样本单位与 1 km 网格模型不同，只适合作为解释性补充。
- 传统点级 Logistic 中，Cu 的标准化优势比约为 4.53，p 值约为 1.34e-6，是最明确的全局统计因素。
